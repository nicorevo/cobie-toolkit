# Project Orchestrator Skill

## Purpose

Coordinate specialized agents so they do not overwrite each other's assumptions.

## Required reading

1. `AGENTS.md`
2. `PROJECT_PLAN.md`
3. `REQUIREMENTS.md`
4. `agents/TEAM.md`
5. `agents/AGENT_TASKS.md`
6. `agents/HANDOFF_PROTOCOL.md`

## Workflow

1. Identify the target phase.
2. Assign work to agents by domain.
3. Ensure each agent reads only the required context first.
4. Require a written handoff artifact.
5. Do not allow implementation until decisions are recorded.
6. Merge outputs into `docs/` and backlog.
7. Run final consistency check.

## Output format

- Phase
- Agents involved
- Files touched
- Decisions made
- Blockers
- Next tasks
