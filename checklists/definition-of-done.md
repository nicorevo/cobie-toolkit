# Definition of Done

Una modifica è done solo se:

- compila;
- passa typecheck;
- passa lint;
- migrazioni aggiornate se cambia DB;
- RLS aggiornata se cambia accesso dati;
- API documentata se cambia endpoint;
- UI ha loading/error/empty state;
- documentazione aggiornata;
- handoff scritto;
- nessun secret introdotto.
