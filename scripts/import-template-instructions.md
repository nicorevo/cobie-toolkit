# Istruzioni estrazione template

1. Scaricare template con `scripts/download-latest-cobie-template.sh`.
2. Estrarre ZIP in `.local/cobie-templates`.
3. Leggere workbook con script Python/Node non ancora incluso.
4. Estrarre:
   - sheet names;
   - header row;
   - picklists;
   - instruction/status sheet.
5. Generare report diff contro `reference/cobie_sheet_catalog_v24_uk_2026_q2.yaml`.
6. Aggiornare catalogo dopo review.
